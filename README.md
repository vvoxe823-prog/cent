# PlanForge integrated drawing flow

## What changed
- `index.php` now submits to `https://cent-ciaf.onrender.com/generate-plan-drawing` instead of the JSON endpoint.
- `build.py` keeps `/generate-plan` as the JSON API and adds `/generate-plan-drawing`.
- `drawing_renderer.py` creates the SVG drawing server-side from the actual generated layout.
- `layout_engine.py` is the uploaded layout engine and remains unchanged.
- No AJAX, fetch, sessionStorage, or JavaScript is used to transport/render the plan. The drawing is generated by Python after the normal HTML form POST.

## Render files
Upload/commit these together:
- build.py
- layout_engine.py
- drawing_renderer.py
- requirements.txt

Start command can remain:
`python build.py`

## Frontend
Use the supplied `index.php`. Its form still opens a new tab, but the new tab is now the architectural drawing instead of raw JSON.

## Important
The drawing is a preliminary architectural visualization. It is not a construction drawing and does not replace a licensed architect/engineer, statutory approval, structural design, fire/life-safety review, or local setback/bylaw verification.
